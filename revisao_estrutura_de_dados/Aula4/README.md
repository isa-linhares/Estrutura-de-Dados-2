# Atividade – Pilhas e Filas

Nesta pasta foram realizadas atividades sobre Pilhas e Filas, utilizando situações do dia a dia para entender esses conceitos.

No primeiro exercício, foi criado um sistema de desfazer ações, utilizando uma pilha para registrar ações e desfazer a última realizada. No segundo, foi desenvolvido um sistema de impressão, utilizando uma fila para organizar os documentos na ordem em que serão impressos.

Por fim, foi desenvolvido um sistema de atendimento médico, utilizando deque, onde pacientes normais entram no final da fila e pacientes prioritários são colocados no início.
