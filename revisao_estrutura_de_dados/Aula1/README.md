**Estrutura de Dados 1**

Este projeto foi desenvolvido para a matéria de Estrutura de Dados 1, utilizando a linguagem C.

O código trabalha com vetores e algoritmos de ordenação, permitindo ao usuário inserir, limpar e visualizar valores, além de ordenar os dados utilizando os métodos Bubble Sort, Selection Sort e Insertion Sort. Também é possível preencher o vetor automaticamente com números aleatórios.

O objetivo foi praticar os conceitos de vetores, funções, estruturas de repetição e ordenação de dados.
