# Ponteiros, Referências e Estruturas Dinâmicas em Python

As atividades abordaram o funcionamento de referências na memória, a criação e ligação de nós em uma estrutura encadeada, a identificação e correção de erros em códigos e, por fim, a criação de um sistema de atendimento de uma clínica, utilizando filas para organizar os pacientes por prioridade.
